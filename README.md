# ⚡ QuizMaster — Interactive Web Quiz App

QuizMaster is a fully interactive quiz application built using **pure HTML, CSS, and JavaScript** — no frameworks required.
It includes **difficulty modes, per-question timers, scoring logic, sound effects, a share-card generator, and a persistent LocalStorage leaderboard**.


## ✅ Features

* ⏱️ **Countdown timer** for each question
* 🎚️ **Difficulty levels** (Easy / Medium / Hard)
* 🧠 **Score calculation** with speed-bonus
* 🔊 **Sound effects** (toggleable)
* ✅ **Correct/Incorrect** visual indicators
* 🏆 **Leaderboard** using LocalStorage (Top 10 saved)
* 🎴 **Downloadable share card** generated on canvas
* 🔄 **Reset leaderboard** button
* ↩️ **Quit quiz** option
* 🎲 **Optional shuffle mode**
* ⚡ Works in any browser — no backend required


## 📦 Tech Stack

* **HTML5** – structure
* **CSS3** – UI, animations, responsive layout
* **JavaScript (Vanilla)** – quiz engine, timer, sounds, share-card
* **Canvas API** – screenshot/share card generator
* **LocalStorage** – save high scores


## 🚀 How to Run

1. Download or clone the repository:

   ```bash
   git clone https://github.com/yourusername/quizmaster.git
   ```
2. Open the folder.
3. Double-click **index.html** to run the quiz in your browser.

✅ No build tools
✅ No server setup
✅ No dependencies
